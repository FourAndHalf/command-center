# Projects

Projects are a reusable daily companion for the Command Center decision loop.
They preserve what you intended to try, what happened, and what you learned.
They are not a task list or a streak tracker.

## Daily use

1. Open **More → Projects** and choose a project.
2. Before work, choose **Plan session** and write the experiment or focus. Add
   expected evidence when it is useful.
3. Work in the project itself. For Cardboard, its neighboring checklist remains
   the authority for task completion.
4. Afterward, choose **Record result**. Add the result, blocker, lesson and next
   experiment as needed. A result without a prior plan is valid.

Projects can be created with only a name. Milestones, goals, decisions and
source references are optional. The Cardboard starter is copied into the new
project's setup history; changing the starter later cannot rewrite that project.

All records are local and remain useful with AI disabled. Corrections append a
new record so the original expectation and evidence remain visible.
